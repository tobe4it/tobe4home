# Glossary

[Deutsch](DE-Glossary.md) | [English](EN-Start.md)

**Public edition 1.0, 2026-10-14.** Examples do not replace a private deployment inventory.

| Term | Meaning |
| --- | --- |
| ACL | Rules defining allowed operations or topic access |
| ACME / Certbot | Certificate issuance/renewal protocol and a client tool |
| Backup / restore | Preserving and recovering an earlier usable data state |
| Bridge / vmbr | Virtual network connection on the Proxmox host |
| Commit / branch | Recorded Git state / development line |
| Container / image | Running application instance / packaged application |
| DHCP / DNS | Automatic network configuration / name resolution |
| FQDN | Complete service name, such as ldap.example.test |
| Gateway / firewall | Connector between networks / connection rules |
| Inventory / playbook | Ansible target description / task sequence |
| LDAP / LDAPS | Directory protocol / its TLS-protected connection |
| LXC / guest ID | Linux guest environment / Proxmox identifier |
| MFA / 2FA | Additional authentication proof beyond a password |
| Mountpoint / volume | Attached data path / provided storage |
| MQTT / broker / topic | Messaging protocol / distributor / message subject |
| NAS / DSM | Storage computer / Synology management interface |
| OCR / metadata | Text recognition / descriptive document information |
| RPO / RTO | Permitted lost-change interval / recovery-time objective |
| SMTP / IMAP | Sending mail / reading and synchronizing mailboxes |
| Snapshot / RAID | Storage state / disk redundancy; not complete backups |
| SSH / TLS | Encrypted console access / secure connections |
| systemd / unit | Linux service manager / managed task |
| Vault / venv | Encrypted Ansible content / isolated Python environment |
| VLAN / WireGuard | Logical network separation / encrypted private tunnel |

Ask the caretaker to explain an unfamiliar term using the affected device or application. Understanding one concrete example is more useful than memorizing an abbreviation.
