**Öffentliche Ausgabe 1.0, 14.10.2026.** Beispiele ersetzen keine private Standortkonfiguration.

## Wörterbuch für die Übernahme

Diese Begriffe begegnen Ihnen in Oberflächen, Fehlermeldungen und Gesprächen mit der Betreuung.

| Begriff | Einfache Bedeutung |
| --- | --- |
| ACL | Liste, wer welche Vorgänge oder Nachrichten nutzen darf |
| ACME / Certbot | Verfahren / Werkzeug zur Zertifikatsausstellung und Erneuerung |
| Backup / Restore | Sicherung / Wiederherstellung eines früheren Datenstands |
| Bridge / vmbr | Virtuelle Netzverbindung auf dem Proxmox-Host |
| Commit / Branch | Festgehaltener Git-Stand / Entwicklungslinie |
| Container / Image | Gestartete Programminstanz / zugehöriges Programmpaket |
| DHCP / DNS | Automatische Netzkonfiguration / Übersetzung von Namen |
| FQDN | Vollständiger Dienstname, zum Beispiel ldap.example.test |
| Gateway / Firewall | Vermittler zwischen Netzen / Regelwerk für Verbindungen |
| Inventory / Playbook | Ansible-Zielliste / Ablauf von Automationsaufgaben |
| LDAP / LDAPS | Kontenverzeichnis / TLS-geschützter LDAP-Zugang |
| LXC / VMID | Linux-Gastumgebung / ihre Proxmox-Kennnummer |
| MFA / 2FA | Zusätzlicher Anmeldenachweis neben dem Passwort |
| Mountpoint / Volume | Eingebundener Datenort / bereitgestellter Speicher |
| MQTT / Broker / Topic | Nachrichtenprotokoll / Verteiler / Themenadresse |
| NAS / DSM | Speicherrechner / Synology-Verwaltungsoberfläche |
| OCR / Metadaten | Texterkennung / Angaben über ein Dokument |
| RPO / RTO | Erlaubter Datenverlust-Zeitraum / angestrebte Ausfalldauer |
| SMTP / IMAP | Mail übertragen / Postfach lesen und synchronisieren |
| Snapshot / RAID | Speicherzustand / Plattenverbund; keine vollständigen Backups |
| SSH / TLS | Verschlüsselte Verwaltungskonsole / sichere Verbindungen |
| systemd / Unit | Linux-Dienstverwaltung / verwaltete Aufgabe |
| Vault / venv | Verschlüsselte Ansible-Werte / getrennte Python-Umgebung |
| VLAN / WireGuard | Logisch getrenntes Netz / verschlüsselter privater Tunnel |

**Wenn ein Begriff unklar bleibt:** Lassen Sie sich seine Bedeutung an genau dem betroffenen Gerät oder Dienst zeigen. Bei einer Übernahme ist ein konkretes Beispiel hilfreicher als eine auswendig gelernte Abkürzung.
